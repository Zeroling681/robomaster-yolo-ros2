# 外接摄像头 camera_v13 平放杯子标注批次

在 X-AnyLabeling 中直接打开本目录。图片与同名 JSON 必须保留在同一目录。

- 类别：`mouse`、`cup`。
- 标注每个可见鼠标和水杯/保温杯；被手部分遮挡时仍标可见物体的完整外接框。
- 没有目标的画面保持空 JSON，作为困难负样本。
- 不要把显示器、人物、桌面、线缆、笔记本或普通瓶子标为目标。
- 完成后不要改文件名，回复“标注完成”。

## 本轮预标注

- 原始视频时长约 153 秒，从中筛选了 80 张清晰且尽量不重复的图片。
- v12 ONNX 初始预测共生成 142 个框：`mouse` 100 个、`cup` 42 个。
- 24 张图片没有模型框，这些图片仍然需要逐张查看，不能直接当作负样本。
- 当前所有 JSON 均保持 `checked=false`，只有人工复核后才能合并进训练集。

本批次重点是补充杯子横放、斜放、远距离、地面背景、手持遮挡和不同环境。
旧模型会把部分横放的蓝色杯、不锈钢杯预测成 `mouse`。复核时应把这类错误框
改为 `cup`，并重新调整外接框；漏掉的横放杯也需要手工补框。画面里原有的真实
鼠标仍按 `mouse` 标注。预标注统计和空预测清单见 `PRELABEL_REVIEW.csv`。
