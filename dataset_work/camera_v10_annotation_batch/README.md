# 外接摄像头 camera_v10 标注批次

在 X-AnyLabeling 中直接打开本目录。图片与同名 JSON 必须保留在同一目录。

- 类别：`mouse`、`cup`。
- 标注每个可见鼠标和水杯/保温杯；被手部分遮挡时仍标可见物体的完整外接框。
- 没有目标的画面保持空 JSON，作为困难负样本。
- 不要把显示器、人物、桌面、线缆、笔记本或普通瓶子标为目标。
- 完成后不要改文件名，回复“标注完成”。
